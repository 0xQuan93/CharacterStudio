Local authoring workflow

From a model to an editable avatar

Start with Quan’s clean reference. Inspect and convert a rigged GLB or FBX through Blender, then open the VRM in Character Studio for sculpting, painting and variations.

1. Inspect the source

The local converter accepts .glb and .fbx. Run a preflight before conversion: 

/home/oxquan/Work/avatar-tools/conversion/convert.sh "/path/to/model.glb" --output "/path/to/new-inspection" --preflight

The output folder must be new. Keep the source file. The report identifies geometry, skinning and humanoid mapping; the Blender authoring file is retained for repair.

2. Prepare the humanoid

A skinned humanoid needs correct bone mapping, weights and rest pose. Unrigged image-to-3D output needs a skeleton and weight painting first. Missing blink, mouth shapes, eye motion and hair physics remain authoring work. 

/home/oxquan/Work/avatar-tools/conversion/open-blender.sh

Blender uses the isolated official VRM add-on. Open the saved authoring file to inspect or fix the model. Large changes to proportions require checking joints, clothing and expressions.

If FBX surfaces sort incorrectly or hair shows through the face, review transparency by material. The converter accepts --material-overrides "/path/to/materials.json" with explicit OPAQUE, MASK or BLEND settings. See the example in the local conversion tools folder.

3. Convert and edit

Copy metadata.example.json from the conversion tools folder and fill in the model’s actual title, authors and permissions. Then export: 

/home/oxquan/Work/avatar-tools/conversion/convert.sh "/path/to/model.glb" --output "/path/to/new-avatar" --metadata "/path/to/metadata.json"

If a checked model faces backward, add --yaw-degrees 180 and use a new output folder. This rotates the whole imported character once; inspect the front view after conversion.

Review report.json, keep authoring.blend, and import model.vrm using ＋ in Character Studio. Check materials and skin tone, try expressions and motion, then save a portable project before sculpting.

A file extension does not create a humanoid rig or restore missing expressions. The conversion report and a motion check determine whether the avatar is ready to use.
